Bitácora de la app Python TK (Authorization: Bearer)

El cliente de escritorio mostrando en la terminal cada petición con el encabezado del token y el refresco automático al recibir un 401.

 APP PYTHON TK - SERVICIOS CON JWT
====================================================================================
====================================================================================
 CLIENTE DE ESCRITORIO DE LA LIBRERIA - microservicios + JWT (RFC 7519)
====================================================================================
 Microservicio de login  : http://127.0.0.1:5000
 Microservicio de libros : http://127.0.0.1:5001
 Esquema de autorizacion : Authorization: Bearer <access_token>
 Metodos publicos (libros): GET /books y GET /books/{isbn} (sin token)
 Metodos protegidos       : POST / PUT / PATCH / DELETE (exigen token)
------------------------------------------------------------------------------------
 Credencial en memoria    : (ninguna: la sesion inicia sin token)
 Renovacion automatica    : activa (POST /refresh al recibir 401)
